# Founder Intent — AgencyOS / SSA

**Founders in scope:** Alex Lobaido (Bloomfield), Kamal, Manny  
**Sources:** Alex Call 01 & 02 (2026-08-04)  
**Use:** Load this when an agent needs “why we exist” without replaying full call notes.

---

## Intent in one paragraph

Alex wants SSA to make serious money **and** leave something real behind: an Agent OS + community + software layer that helps people start AI agencies, brings them closer to God, and creates enterprise value that is not wiped out when ad spend stops. Kamal’s job is to turn that into an organized, patient, technical build. Manny is part of the operating core. The system should sound like Alex, sell and nurture like Alex, and eventually audit/optimize the business with less human babysitting.

---

## North-star outcomes

1. **Help many people** learn AI agency work and get results faster with less risk.
2. **Make money for the partners** with healthier unit economics (AOV > CAC; recurring community).
3. **Own durable assets** (Agent OS, data loops, software/community) that can be sold or scaled.
4. **Bring people closer to God** while building — mission is not optional flavor text for Alex.
5. **Reduce founder bottleneck** — Agent OS acts with budget authority instead of pinging Alex for every step.

---

## How we win (founder’s mental model)

| Old pattern | New pattern |
|---|---|
| Ads → $97 → hard upsell Inner Circle / DFY | Ads → $97 → software/value upsell → course excellence → opt-in community |
| Expensive offers; confused buyers | Cheaper offers; Agent OS delivers competence |
| Revenue dies when ads pause | Users + MRR + software remain |
| Manual sales grind | AI sells/nurtures; fewer calls |
| Kamal waits on Alex for every detail | Funded Agent OS + clear game plan |

---

## Non-negotiables

- Students get **their own GHL agency accounts** (not SSA sub-accounts).
- The AI voice/outbound should be **Alex** (knowledge base + cadence + iMessage).
- Learn first from **closed** conversations and real call transcripts.
- Prefer **value delivery** over aggressive in-course upsells.
- Combine **Kamal’s organization** with **Alex’s speed** — neither alone is the product.

---

## Partnership intent

- Working model discussed: **Alex / Manny / Kamal** as the core; hypothetical even split **33/33/33**.
- Kamal defines what Manny can take over so execution is not only on Alex+Kamal.
- Alex contributes: cash capacity, 5k leads, 40+ testimonials, sales/marketing, consulting.
- Kamal contributes: tech, Agent OS build, patience, systems.

---

## What “done” feels like to the founder

- Agent OS can audit SSA, propose ad/School/content moves, and execute bounded work with a spend card.
- Lead archive is scored, nurtured, and converting without Alex living in DMs.
- Front-end can scale because AOV and fulfillment quality support it.
- Community members stay because of value, not because every lesson asks for $5–7k.
- There is a sellable software/OS asset — not only an ad account and a course library.
