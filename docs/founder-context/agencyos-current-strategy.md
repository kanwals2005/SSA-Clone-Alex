# AgencyOS — Current Strategy

**Owner:** Alex Lobaido (Bloomfield) + Kamal (+ Manny)  
**Business surface:** SSA (agency-education / AI-agency training business)  
**Last updated from:** `alex-call-01.md`, `alex-call-02.md` (2026-08-04 recordings)  
**Product name in use here:** AgencyOS / Agent OS (Hermes + MCP loop)

---

## One-sentence strategy

Turn SSA from an ads-dependent info product into an **Agent-OS-powered operating system** that raises front-end AOV, lowers high-ticket friction, monetizes existing leads, and creates **software/community enterprise value** that survives when ads pause.

---

## Strategic pillars

### 1. Fix unit economics on the front end
- Keep / improve the **$97** VSL offer.
- Add a software/feature upsell so AOV clears **$70–$140 CAC**.
- Goal: more ad spend → more leads → more cash for partners without drowning in sales calls.

### 2. Replace expensive confusion with cheaper competence
- Legacy ladder: Inner Circle **$5–7k**, DFY **$25k**.
- New posture: **lower price, higher delivered value, less buyer risk** — made possible by Agent OS doing real work for students.

### 3. Build what remains when ads stop
- Info revenue alone is fragile.
- Ship something students **use daily** (workflows, Agent OS, GHL tooling, community) that becomes sellable enterprise value.

### 4. Monetize the 5k lead archive before more chaos
- Audit tags/buckets.
- Score + nurture with an Alex-clone AI (iMessage + email).
- Convert dormant inventory to cash → reinvest.

### 5. Community over hard upsell
- Stop pitching Inner Circle in every video.
- Deliver extreme course value; let **$100–200/mo** private community be opt-in.
- Affiliates (e.g. GHL Command) only where they do not poison trust.

### 6. Operate with Hermes, not heroics
- Funded agent card, MCPs, looping system, dashboards.
- Possible multi-Agent-OS split: sales / marketing / fulfillment / CS-nurture.
- Agent eventually proposes ad scale, creative, and School moves from live metrics.

## Constraints that shape strategy

- Students **must** own their own GHL agency accounts.
- Do not recreate “upsell in every lesson” culture.
- Prefer configuring/integrating owned stack (GHL, Hermes, MCP) before net-new platforms.
- Kamal owns organized execution; Alex owns sales/marketing speed and voice.

## Explicit non-strategies

- Putting students inside SSA sub-accounts.
- Scaling ad spend before AOV/CAC is fixed.
- Building a GHL clone “because we can” if native MCP lands soon.
- Maximizing short-term Inner Circle closes at the expense of community.
