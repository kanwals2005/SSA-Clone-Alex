## Lead intelligence system (Alex + Kamal vision)

### Assets already in GHL
- ~5–6k leads (Instagram / Facebook DMs and related threads).
- Tags on contacts (more tags ≈ higher buy likelihood; more content consumed ≈ higher buy likelihood).
- ~**200 sales-call recordings/transcripts**.
- Closed deals as the gold set for style + ICP.

### What the AI must do
1. **Scan every conversation** (SMS/iMessage-style threads).
2. **Score leads**; inspect why high scores win; learn only from **closed** conversation patterns first.
3. Find **gaps** in non-closed threads and infer how they could have closed.
4. Build **ICP** from closed buyers (tags, credit/qualification fields, intake answers).
5. Detect **drop-off phrases** and winning **word-for-word** reply patterns.
6. Run a **message experiment loop:** hypothesize → send → score replies → optimize continuously.
7. Pair nurture with **email** that requires open/click for value; track opens to improve deliverability.
8. A/B **direct CTA** vs **relationship nurture** (origin, work, family, goals; use Alex life knowledge base), then invite to private community after days.
9. Human-like cadence: chat for a bit → go quiet ~1.5 days → continue; auto follow-up if no reply — **bot should sound like Alex**.
10. Outbound channel: **iMessage**; support **templated personalized videos** + PDFs/docs; ask what they thought to confirm consumption.
11. Mine **200 call transcripts** for repeated pains → feed messaging, marketing, and fulfillment.
12. Long-term: **Hermes / Agent OS** with an **agent spend card** creates docs/PDFs/landing pages from knowledge + transcripts, monitors reply rate / email opens / ad numbers, audits the business, and recommends scale-up/down of ads, School, and content.
