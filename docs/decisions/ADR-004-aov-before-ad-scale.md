# ADR-004: Raise Front-End AOV Before Scaling Ad Spend

**Status:** Accepted  
**Date:** 2026-08-08  
**Source:** Alex Call 01  

## Context

CPP sits roughly **$70–$140** on a **$97** front end. Without upsells, scaling ads destroys margin. Software can now be built quickly enough to sell a tool/feature that helps students get customers faster.

## Decision

Prioritize a front-end **AOV upsell** (tool, feature, or acceleration asset) aligned to VSL promises before materially increasing ad spend. High-ticket prices should move **down** while delivered value/risk mitigation move **up** via Agent OS.

## Consequences

- VSL + checkout audit is required work.
- Ad scale is gated on AOV/CAC evidence.
- DFY $25k / Inner Circle $5–7k are not the default future ladder without redesign.
