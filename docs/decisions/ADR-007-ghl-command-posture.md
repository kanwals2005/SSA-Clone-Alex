# ADR-007: GHL Command — Prefer Wait/Affiliate Over Immediate Rebuild

**Status:** Accepted (provisional)  
**Date:** 2026-08-08  
**Source:** Alex Call 02  

## Context

GHL Command (~$97/mo, ~40% recurring affiliate) lets users edit/create workflows inside GHL. Kamal could rebuild similar software. GHL is also shipping/improving native MCP, which may commoditize custom command tooling.

## Decision

Do **not** prioritize building a GHL Command clone immediately. Prefer (1) affiliate monetization if it does not harm community trust, and/or (2) wait to evaluate native GHL MCP before investing in a parallel product. Revisit only if MCP gaps remain after a real pilot.

## Consequences

- Engineering focus stays on AgencyOS lead intelligence, AOV upsell, and Hermes ops.
- Affiliate experiments must obey ADR-002 (value-first).
- Re-open this ADR if GHL MCP clearly will not cover student workflow needs.
